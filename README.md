# AI在庫発注ゲート

### 発注候補を、確認できる注文へ — AIDE ARK GATE Concept Demo

AIが販売傾向などから在庫補充案を作り、AIDE ARK GATEが発注前に必要な条件を確認する、業務向けの将来構想です。

## アイデア

AIの発注提案だけで注文へ進むと、在庫データの更新遅れや入荷予定の見落としにより、欠品、二重発注、過剰在庫が起きる可能性があります。

この構想では、AIの提案と実際の発注判断を分け、根拠や権限を確認できない場合は処理を保留します。

## 想定する流れ

1. Geminiが販売傾向や在庫情報をもとに、補充する品目と数量を候補として提示します。
2. AIDE ARK GATEが在庫データの更新時刻、入荷予定、未着発注、仕入先、単価、予算、承認権限を確認する構想です。
3. 在庫情報が古い、または未着発注の状況を確認できない場合は **HOLD（保留）** とし、発注へ進みません。
4. 担当者が情報を確認・更新した後に再評価します。
5. 発注の最終承認は担当者が行います。

## AIの役割と実行境界

* **Gemini**：在庫補充の候補を提案します。提案は発注許可ではありません。
* **AIDE ARK GATE**：発注前の情報鮮度、条件、権限を独立して確認し、不確かな場合は保留する構想です。
* **担当者**：情報を確認し、発注を承認します。

## 応用の可能性

小売商品のほか、製造部品や事務用品など、在庫と入荷の状況を確認して発注する業務への応用を想定しています。

## 現在の範囲

このリポジトリは**将来構想の説明資料**です。在庫管理システム、購買機能、仕入先連携、発注APIは実装していません。動画内の在庫・発注シナリオはコンセプトを示すものです。実際の注文や決済は行いません。

Gemini API連携と構造評価の動作確認は、架空送金を用いた別シナリオで行っています。このリポジトリの在庫発注機能を実装したものではありません。
